# 학습 계획과 문제 풀이

[SAA 목차](/en/Study/AWS/Certification/SAA)

## 1. 학습 목표

각 서비스의 목적뿐 아니라 선택 조건과 한계를 설명하는 것을 목표로 한다. 개념 → 비교표 → 아키텍처 흐름 순서로 학습한다.

## 2. 4주 기본 계획

하루 1.5~2시간, 주 6일을 가정한 시작안이다. 경험과 시험일까지 남은 시간에 맞춰 늘리거나 줄인다. 정해진 기간 자체보다 설명 능력과 처음 보는 문제의 성적을 기준으로 진도를 판단한다.

| 주차 | 학습 | 문제 풀이·확인 |
|---|---|---|
| 1주 | IAM, VPC, EC2, ALB, ASG | 요청 한 건의 네트워크 경로를 그린다. 역할과 정책의 차이를 설명한다. |
| 2주 | S3, EBS, EFS, FSx, RDS, Aurora, DynamoDB | 스토리지·DB 비교표를 가리고 요구사항별 서비스를 고른다. |
| 3주 | SQS, SNS, EventBridge, Lambda, 분석, 이전, DR | 장애·트래픽 급증·재시도 시나리오를 풀고 실패 흐름을 그린다. |
| 4주 | 비용·운영, 약점 보완, 공식 범위 대조 | 처음 보는 모의문제 65문항을 130분 안에 풀고 오답을 다시 설명한다. |

### 하루 학습 루틴

| 시간 | 활동 |
|---|---|
| 15분 | 이전 오답을 답 없이 재풀이 |
| 40분 | 개념 한 주제와 비교표 학습 |
| 30분 | 연습문제 10~15개 풀이 |
| 25분 | 오답·추측 정답의 근거 검증 |

문제 수는 제안이다. 이해가 부족하면 문제 수를 줄이고 검증 시간을 늘린다.

## 3. 문제를 푸는 순서

1. **목적**을 찾는다: 읽기 성능, 장애 복구, 보안 강화, 비용 절감 중 무엇인가?
2. **필수 조건**을 적는다: 데이터 손실 불가, SMB 유지, 인터넷 경유 불가, 코드 변경 최소화 등.
3. **최적화 기준**을 찾는다: 최소 비용, 최소 운영 부담, 최소 지연 등.
4. 필수 조건을 위반하는 선택지를 먼저 지운다.
5. 남은 선택지의 운영 부담과 비용을 비교한다.
6. 복수 선택 문제는 요구한 선택 개수를 확인한다.

예: “매일 1시간 실행하는 중단·재실행 가능한 배치의 비용을 줄인다.”

- 중단 허용 → Spot을 후보로 둔다.
- 재실행 가능 → 체크포인트와 재시도 구조를 확인한다.
- 항상 켜 두는 큰 인스턴스는 유휴 비용이 발생한다.
- 작업 실행 시간·런타임 제약에 맞으면 서버리스 배치 구성도 비교한다.

키워드는 후보를 좁히는 단서이다. “배치=무조건 Spot”처럼 한 단어로 답을 고르지 않는다.

## 4. 아키텍처로 기억하기

```text
사용자 → Route 53 → CloudFront / WAF → ALB
                                      ↓
                            프라이빗 앱 계층 (여러 AZ)
                               ↓             ↓
                       DB / 공유 캐시      SQS → Worker
                               ↓
                          백업 / 복구
```

각 화살표에 대해 “라우팅은 되는가, 권한은 있는가, 암호화되는가, 장애가 나면 어떻게 되는가, 어떤 비용이 드는가”를 확인한다. 서비스 이름을 외우는 것보다 전체 경로를 설명하는 연습이 중요하다.

## 5. 실습으로 확인할 최소 항목

| 실습 | 확인할 것 |
|---|---|
| IAM 역할로 S3 접근 | 정적 액세스 키 없이 접근, 정책 제거 시 거부 |
| VPC 구조 읽기 | 퍼블릭·프라이빗 서브넷과 라우팅 테이블 관계 |
| S3 버전 관리 | 덮어쓰기 후 이전 버전 확인 |
| SQS 메시지 처리 | 수신과 삭제가 다름, 미삭제 시 재전달 |
| ALB·ASG 구조 설명 | 비정상 대상 제외와 인스턴스 교체의 차이 |

실습은 예산 알림을 먼저 설정하고 작은 범위로 진행한다. NAT Gateway·로드 밸런서·DB 등은 사용하지 않는 시간에도 비용이 생길 수 있으므로 종료 후 리소스를 정리한다. 실제 배포 없이 콘솔과 공식 구성도를 읽는 연습으로 시작해도 된다.
