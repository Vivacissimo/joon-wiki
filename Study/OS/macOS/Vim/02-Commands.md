# 02. Vim Commands

Vim 명령어는 **Normal Mode**를 기준으로 정리한다. 다른 모드에 있다면 `Esc`로 돌아온 뒤 입력한다. `Ctrl+r`는 Ctrl 키를 누른 상태에서 r을 입력한다는 의미다.

## 1. 저장 및 종료

| 명령어 | 동작 |
| --- | --- |
| `:w` | 저장 |
| `:w 파일명` | 지정한 파일명으로 저장 |
| `:q` | 종료. 미저장 변경 사항이 있으면 종료하지 않음 |
| `:q!` | 현재 버퍼의 변경 사항을 버리고 강제 종료 |
| `:wq` | 저장 후 종료 |
| `:x` | 변경 사항이 있으면 저장하고 종료 |
| `ZZ` | 저장 후 종료 (Normal Mode에서 대문자 Z 두 번) |
| `:e 파일명` | 다른 파일 열기 |
| `:e!` | 저장하지 않은 현재 변경 사항을 버리고 디스크의 파일 다시 읽기 |

` :q! `는 현재 버퍼에서 저장하지 않은 변경을 버린다. 다른 버퍼나 파일을 전부 저장·종료하는 명령은 아니다.

<br>

## 2. 입력 모드

| 명령어 | 동작 |
| --- | --- |
| `i` | 커서 앞에서 입력 |
| `I` | 현재 줄의 첫 비공백 문자 앞에서 입력 |
| `a` | 커서 뒤에서 입력 |
| `A` | 현재 줄 끝에서 입력 |
| `o` | 아래에 새 줄을 만들고 입력 |
| `O` | 위에 새 줄을 만들고 입력 |
| `Esc` | Normal Mode로 복귀 |

<br>

## 3. 커서 이동

| 명령어 | 동작 |
| --- | --- |
| `h` / `j` / `k` / `l` | 왼쪽 / 아래 / 위 / 오른쪽 |
| `w` | 다음 단어 시작 |
| `b` | 이전 단어 시작 |
| `e` | 단어 끝 |
| `0` | 줄의 맨 앞 |
| `^` | 줄의 첫 비공백 문자 |
| `$` | 줄의 맨 끝 |
| `gg` | 파일 첫 줄 |
| `G` | 파일 마지막 줄 |
| `숫자G` | 지정한 줄로 이동 (예: `25G`) |
| `:숫자` | 지정한 줄로 이동 (예: `:25`) |
| `Ctrl+f` / `Ctrl+b` | 한 화면 아래 / 위 |
| `Ctrl+d` / `Ctrl+u` | 반 화면 아래 / 위 |
| `%` | 짝이 되는 괄호로 이동 |

대부분의 이동 명령 앞에는 횟수를 붙일 수 있다. `5j`는 아래로 5줄, `3w`는 다음 단어 방향으로 세 번 이동한다.

<br>

## 4. 복사·삭제·붙여넣기

| 명령어 | 동작 |
| --- | --- |
| `yy` | 현재 줄 복사 |
| `3yy` | 현재 줄부터 3줄 복사 |
| `dd` | 현재 줄 삭제 |
| `3dd` | 현재 줄부터 3줄 삭제 |
| `x` | 커서 위치의 문자 삭제 |
| `dw` | 현재 위치부터 다음 단어 시작까지 삭제 |
| `d$` / `D` | 커서부터 줄 끝까지 삭제 |
| `p` | 커서 뒤 또는 다음 줄에 붙여넣기 |
| `P` | 커서 앞 또는 이전 줄에 붙여넣기 |
| `u` | 실행 취소 |
| `Ctrl+r` | 취소한 작업 다시 실행 |
| `.` | 마지막 편집 명령 반복 |

Vim에서 `dd`로 삭제한 줄은 레지스터에 들어가므로 `p`로 붙여넣을 수 있다.

<br>

## 5. 선택 및 들여쓰기

| 명령어 | 동작 |
| --- | --- |
| `v` | 문자 단위 선택 |
| `V` | 줄 단위 선택 |
| `Ctrl+v` | 블록 단위 선택 |
| `y` | 선택 영역 복사 |
| `d` | 선택 영역 삭제 |
| `>` / `<` | 선택 영역 들여쓰기 / 내어쓰기 |
| `>>` / `<<` | 현재 줄 들여쓰기 / 내어쓰기 |
| `gg=G` | 파일 전체를 Vim의 들여쓰기 규칙으로 다시 정렬 |

예: Kubernetes YAML의 여러 줄을 선택할 때 `V`를 누르고 `j`로 범위를 확장한 뒤 `>` 또는 `<`를 입력한다. YAML 들여쓰기는 실제 구조가 달라질 수 있으므로 저장 전에 확인한다.

<br>

## 6. 검색 및 치환

| 명령어 | 동작 |
| --- | --- |
| `/문자열` | 아래 방향 검색 |
| `?문자열` | 위 방향 검색 |
| `n` / `N` | 같은 방향 다음 결과 / 반대 방향 결과 |
| `*` / `#` | 커서 위 단어를 아래 / 위 방향 검색 |
| `:nohlsearch` | 검색 결과 강조 해제 |
| `:s/old/new/` | 현재 줄의 첫 일치 항목 치환 |
| `:s/old/new/g` | 현재 줄의 모든 일치 항목 치환 |
| `:%s/old/new/g` | 파일 전체에서 치환 |
| `:%s/old/new/gc` | 파일 전체 치환 시 일치 항목마다 확인 |

```vim
:%s/nginx:latest/nginx:1.27/gc
```

<br>

## 7. 버퍼·창·탭

| 명령어 | 동작 |
| --- | --- |
| `:ls` | 열린 버퍼 목록 |
| `:bnext` / `:bprev` | 다음 / 이전 버퍼 |
| `:split 파일명` | 가로 분할 |
| `:vsplit 파일명` | 세로 분할 |
| `Ctrl+w w` | 다음 창으로 이동 |
| `Ctrl+w h/j/k/l` | 왼쪽/아래/위/오른쪽 창으로 이동 |
| `:close` | 현재 분할 창 닫기 |
| `:tabnew 파일명` | 새 탭에서 파일 열기 |
| `gt` / `gT` | 다음 / 이전 탭 |

## 8. 설정 및 도움말

| 명령어 | 동작 |
| --- | --- |
| `:set number` | 줄 번호 켜기 |
| `:set nonumber` | 줄 번호 끄기 |
| `:set paste` | 붙여넣기용 모드 켜기 |
| `:set nopaste` | 붙여넣기용 모드 끄기 |
| `:set filetype?` | 현재 파일 타입 확인 |
| `:set shiftwidth?` | 현재 들여쓰기 너비 확인 |
| `:source ~/.vimrc` | Vim 설정 다시 불러오기 |
| `:help 명령어` | 해당 명령어 도움말 |

### .vimrc 사용자 단축키

아래는 **기본 Vim 명령어가 아니라 직접 매핑했을 때만 동작**한다.

```vim
let mapleader = " "
nnoremap <leader>w :w<CR>
nnoremap <leader>q :q<CR>
nnoremap <leader>x :wq<CR>
nnoremap <leader>h :nohlsearch<CR>
nnoremap <leader>e :Explore<CR>
```

| 단축키 | 동작 |
| --- | --- |
| `Space → w` | 저장 |
| `Space → q` | 종료 |
| `Space → x` | 저장 후 종료 |
| `Space → h` | 검색 강조 해제 |
| `Space → e` | 파일 탐색기 |

설정 파일은 `~/.vimrc`에서 읽는다. 현재 dotfiles 방식에서는 `~/.vimrc → ~/dotfiles/vim/.vimrc` 심볼릭 링크로 연결한다.

<br>

## 9. 자주 쓰는 작업 순서

**파일 수정 후 저장**

```text
vim values.yaml → i → 내용 수정 → Esc → :wq
```

**파일을 수정했지만 취소**

```text
Esc → :q!
```

**특정 줄 이동 후 검색**

```text
:50 → /image: → n
```

**현재 줄 복사 후 붙여넣기**

```text
yy → 3j → p
```
