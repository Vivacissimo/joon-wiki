# withU 제품 개요

## 1. 서비스 정의

withU는 커플이 둘만의 하루와 추억을 기록하고 서로 소통할 수 있는 iOS 앱이다.

핵심은 아래 네 가지다.

1. **다이어리** — 그날 무엇을 했는지 함께 기록
2. **사진** — 추억 사진을 여러 장 첨부
3. **소통** — 상대방 글에 댓글과 이모티콘 반응
4. **일정** — 둘이 함께 볼 수 있는 공유 일정

## 2. 주요 사용자 흐름

```text
회원가입 / 로그인
      ↓
커플 연결
      ↓
둘만의 공간 생성
      ↓
┌──────────────┬──────────────┐
│              │              │
다이어리 작성   일정 등록 / 공유
│              │
사진 첨부       캘린더 확인
│
상대방 확인
│
댓글 / 반응
└──────────────┘
```

## 3. 화면 구성

- 홈
- 다이어리 피드
- 다이어리 작성
- 다이어리 상세
- 캘린더
- 일정 작성 / 수정
- Apple Calendar 가져오기
- 우리

## 4. 제품 방향

withU는 단순 SNS보다 **커플의 시간을 쌓는 개인 공간**에 가깝게 설계한다.

다이어리와 캘린더를 연결해서 과거의 기록과 앞으로의 일정을 한 흐름 안에서 볼 수 있게 하는 것이 핵심이다.
