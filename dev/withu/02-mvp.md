# withU 1차 MVP

## 1. MVP 목표

1차 MVP의 목표는 아래 사용자 흐름이 실제 기기 두 대에서 완전히 동작하도록 만드는 것이다.

```text
A 회원가입
   ↓
B와 커플 연결
   ↓
A가 글 + 사진 작성
   ↓
B가 확인
   ↓
B가 댓글 / 반응
   ↓
둘이 일정 등록 및 공유
```

| 다이어리 | 사진 여러 장 첨부 | ✅ |
| 다이어리 | 기분 이모티콘 | ✅ |
| 다이어리 | 피드 / 상세 | ✅ |
| 반응 | 다이어리 이모티콘 반응 | ✅ |

## 5. 가장 먼저 검증할 시나리오

**A가 사진이 포함된 다이어리를 작성하고, B가 자신의 iPhone에서 해당 다이어리를 확인한 뒤 댓글과 반응을 남길 수 있는가?**

이 시나리오가 성공하면 인증, 커플 권한, API, DB, 이미지 저장, iOS UI가 한 번에 연결된 것이다.
